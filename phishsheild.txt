# Implementation Plan - PhishShield AI Phishing Detector

PhishShield AI is a state-of-the-art, premium phishing detection suite designed to analyze potential digital threats in real-time. It combines URL intelligence, NLP threat detection (using a pre-trained Hugging Face transformer model), and QR code extraction with an Explainable AI (XAI) engine to give users rich, actionable security explanations instead of just opaque risk scores.

The application consists of a high-performance **FastAPI backend** and a visually gorgeous, interactive **React frontend** built with premium design principles (glassmorphism, vibrant gradients, rich micro-animations, and responsive layout).

---

## User Review Required

> [!IMPORTANT]
> **1. Choice of Transformer Model**
> For high-quality, out-of-the-box predictions without manual training, we propose using a lightweight Hugging Face model fine-tuned for phishing and spam classification:
> - **Primary Option:** `mrm8488/bert-tiny-finetuned-sms-spam-detection` (extremely lightweight, ~17MB, downloads instantly, runs perfectly on CPU).
> - **Alternative Option:** `Subha5/distilbert-phishing-detector` (standard DistilBERT fine-tuned for phishing, ~260MB, highly accurate but requires more RAM and disk space).
> - *Recommendation:* We will implement a flexible scanner that defaults to a lightweight model and falls back to a custom heuristic model if there are networking issues downloading from Hugging Face, ensuring the app is 100% reliable.
>
> **2. QR Scanner Fallback Mechanics**
> Python `pyzbar` depends on system-level `zbar` libraries which can sometimes fail to load on Windows if visual C++ redists or DLLs are missing. 
> - *Solution:* We will build a dual-engine QR decoder. It will try `pyzbar` first. If `pyzbar` is not available or throws an import/runtime error, it will automatically fall back to OpenCV's native `cv2.QRCodeDetector()`. This guarantees the QR scanner works flawlessly on all Windows setups.
>
> **3. Design System**
> We will implement a premium **Dark Mode Glassmorphism Theme** with vibrant neon borders, animated risk meters, interactive tooltips, and SVG-based micro-interactions.

### Backend Component

The backend will be written in Python using FastAPI. It will expose REST endpoints for text analysis, URL analysis, and QR code extraction.

#### [NEW] [requirements.txt](file:///c:/Users/rrith/Desktop/phishsheildAI/backend/requirements.txt)
- Defines the required dependencies: `fastapi`, `uvicorn`, `transformers`, `torch`, `scikit-learn`, `pandas`, `numpy`, `opencv-python-headless` (to avoid GUI dependency issues), `pyzbar`, `python-multipart`, `tldextract`, `requests`.

#### [NEW] [url_scanner.py](file:///c:/Users/rrith/Desktop/phishsheildAI/backend/scanners/url_scanner.py)
- Domain extraction using `tldextract`.
- Risk indicators:
  - Suspicious TLDs: `.xyz`, `.top`, `.click`, `.club`, `.info`, `.gq`, `.cf`, `.fit`, `.vip`, `.ru`, `.cc`, etc.
  - IP-based hosts (e.g., `192.168.1.1` or hex-encoded hosts).
  - Overly long URLs (length > 75).
  - Keyword matching in subdomain/path: `login`, `verify`, `secure`, `bank`, `update`, `signin`, `account`, `paytm`, `paypal`, `support`.
  - Brand impersonation heuristics (e.g., typosquatting check for brands like `paytm`, `paypal`, `google`, `netflix`, `amazon`).
- Outputs an individual URL risk score (0-100) and specific risk findings.

#### [NEW] [nlp_scanner.py](file:///c:/Users/rrith/Desktop/phishsheildAI/backend/scanners/nlp_scanner.py)
- Integrates Hugging Face `transformers` library.
- Implements a thread-safe pipeline for text classification.
- Automatically handles downloading and caching the model.
- Uses a fallback heuristic classifier (TF-IDF + Cosine Similarity or Keyword density) if the offline mode is triggered or if PyTorch/Transformers has loading issues.

#### [NEW] [qr_scanner.py](file:///c:/Users/rrith/Desktop/phishsheildAI/backend/scanners/qr_scanner.py)
- Receives uploaded image binary data.
- Decodes image using OpenCV (`cv2.imdecode`).
- Decodes QR code:
  - Try decoding with `pyzbar`.
  - Fall back to native `cv2.QRCodeDetector()` if `pyzbar` fails or isn't installed.
- Extracts URL/Text and feeds it into the URL and NLP scanners for complete, seamless integration.

#### [NEW] [explainer.py](file:///c:/Users/rrith/Desktop/phishsheildAI/backend/explainability/explainer.py)
- **Explainable AI (XAI)** core.
- Analyzes text and URL inputs for exact triggers:
  - *Urgency words:* `urgent`, `immediately`, `suspended`, `action required`, `limited time`, `hurry`.
  - *Financial & Reward triggers:* `won`, `lottery`, `cash prize`, `refund`, `verify bank`, `claim reward`.
  - *Credential requests:* `password`, `login here`, `update details`, `reset password`.
  - *OTP scams:* `share otp`, `one time password`, `don't share`, `code`.
  - *Technical anomalies:* suspicious domain structure, IP hostnames, domain-to-brand mismatches.
- Combines the raw model probability with rule findings to output:
  - Comprehensive risk level (`Safe`, `Low Risk`, `Medium Risk`, `High Risk`).
  - Consolidated threat score (Weighted: 40% NLP, 40% URL Heuristics, 20% Keyword heuristics).
  - Bullet-point text explanations of exactly why the classification was made.

#### [NEW] [app.py](file:///c:/Users/rrith/Desktop/phishsheildAI/backend/app.py)
- FastAPI entrypoint setting up CORS, static file assets, and standard exception handlers.
- Endpoints:
  - `POST /analyze-text`: Accepts `text` and/or `url`, returns comprehensive risk assessment.
  - `POST /scan-qr`: Accepts image file, returns decoded contents + risk assessment.
  - `GET /health`: Health-check confirming model load status.
